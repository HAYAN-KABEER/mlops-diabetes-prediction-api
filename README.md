# Diabetes Prediction System - MLOps Assignment

This project is an end-to-end Machine Learning and MLOps implementation for diabetes prediction using a medical dataset. The project includes data preprocessing, exploratory data analysis (EDA), machine learning model training, model evaluation, model saving using Joblib, and deployment using FastAPI with Pydantic validation.

The system predicts whether a patient is diabetic or non-diabetic based on medical attributes such as age, BMI, HbA1c, cholesterol, and other health indicators.

## Features
- Data cleaning and preprocessing using Pandas
- One-hot encoding for categorical variables
- Missing value handling
- Data visualization using Matplotlib and Seaborn
- Multiple ML model training and comparison
- Best model selection and serialization using Joblib
- REST API deployment using FastAPI
- Input validation using Pydantic
- API testing using cURL
- Version control using Git and GitHub
